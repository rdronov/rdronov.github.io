# Privacy Policy

Last updated: 14 October 2026

Personal File Uploader is a personal rclone configuration
operated by its owner.

## Google Drive data

The application accesses Google Drive file contents and
metadata to perform file operations requested by the owner,
including uploads, downloads, updates, moves and deletions.

Downloaded files, OAuth credentials and any enabled logs
are stored on the owner's computer. Uploaded files are
stored in the owner's Google Drive account.

The owner controls retention of local files and logs.
Google Drive files remain until the owner deletes them.

## Sharing

This configuration does not sell Google user data or
intentionally share it with third parties. File operations
communicate with Google's services.

## Website hosting

This informational website is hosted by GitHub Pages.
GitHub may collect visitor information as described in
its own privacy statement.

## Revoking access

The owner can revoke this application's access through
Google Account settings and remove its local rclone
credentials.
