# Personal File Uploader

Personal File Uploader is my private configuration of rclone,
used on my own computer to upload and manage documents in my
Google Drive account.

It can list, download, upload, update, rename, move and delete
files as instructed by me. Access requires Google account
authorisation.

This application is for my personal use and is not offered
as a public service.
